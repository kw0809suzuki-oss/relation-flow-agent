# Flow-chan Abstraction Hypothesis Loop v0

Core contract:

> Flow-chanは方向を作る。
> Modelは構造を見つけて仮説へ落とす。
> Battleは差分を返す。
> 抽象は差分から再生成される。
> そして抽象は常に仮説のまま。

Flow-chan transmits only:
- abstract principle
- search task
- no predefined domain
- no action / ranking / winner

Current abstraction candidate:
> Commitment should track realizable capacity, not merely desired capacity.

Model-side discovery probe:
- seed_surface
- hire_workload
- land_activation

These labels are implementation adapters inside the model body, not Flow-chan instructions.
Each arm activates only when that commitment structure appears in the native plan.

Battle returns only observed differences.
No automatic adoption follows from this run.
