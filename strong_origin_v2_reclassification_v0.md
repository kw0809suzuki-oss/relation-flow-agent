# Strong Origin v2 — Body / Catalog / Knowledge Reclassification v0

Purpose: rebuild a default combat body from already-observed evidence without
turning research knowledge into new policy rules.

## Body candidates

### Frozen Strong Origin normal cycle
Role: default crop / cash / land / labor motion.
Reason: existing strong baseline chassis; no new rule is added here.

### Static livestock loop
Role: bounded COW acquisition / feed / pasture / realization lane.
Body-only v0 uses the original static schedule:
- COW_TARGETS = ((6,2), (10,4), (16,6))
- FEED_CARRY = 3

Dynamic G15 resonance / opponent-phase / Bundle Flow modulation is deliberately
excluded from Body-only v0. Those are treated as Flow-era adaptive layers, not
default body.

### D14 expansion closure
From day 14 onward suppress only:
- BUY_LAND
- BUY_SEED
- BUY_ANIMAL
- BUY_PRODUCT COW

Preserve:
- HIRE
- HARVEST
- unit work
- SELL
- other market operations

Evidence status: robust terminal improvement in prior paired closure runs and
already adopted in the current combat baseline.

### Workforce preservation after closure
Not an extra action rule: preserve native HIRE behavior.
Evidence status: removing HIRE after D14 materially worsened terminal results.
Therefore "do not suppress HIRE" is part of the body boundary.

## Catalog

These operations move the world but are not default-body rules.

- Spatial target reservation / diversification:
  duplicate PLANT can be suppressed, but Day0 terminal worsened.
- Expansion conversion reservation:
  C->R improved strongly, fresh50 terminal self worsened.
- COW first-purchase suppression:
  terminal direction unstable and mean self negative.
- WHEAT3 suppression:
  local cash divergence, terminal neutral.
- WHEAT market netting:
  very large action-volume reduction, terminal self effect small.
- Immediate late HARVEST timing overrides:
  terminal worsened in tested windows.
- Minimal HIRE perturbation:
  near-neutral / inconsistent; no body promotion.

## Knowledge

Observed world structure; not Action policy.

- parallel actors != parallel productive work
- nominal action capacity != effective productive capacity
- Expansion must convert capacity into productive State to matter
- Realization and terminal value are distinct from productive-State formation
- large terminal gap appears mainly as non-WHEAT realized value gap
- LAND timing alone did not explain terminal strength
- co-location itself is not failure; self-side action composition caused
  duplicate PLANT realization loss
- Boundary Reach != Terminal Value

## Body promotion test

A rule belongs in Body only when it:
1. reaches broadly,
2. improves terminal self under fresh paired Battle,
3. requires no narrow special-state diagnosis,
4. does not damage the normal economic cycle.

Everything else stays Catalog or Knowledge.
