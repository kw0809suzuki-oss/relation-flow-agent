# Flow-chan Abstraction Interpretation Bundle v0

## Main line

Flow-chan does one thing:

> transmit a useful abstraction to the model.

It does not implement the downstream answer.

For this probe the abstraction is:

> Preserve future choice when commitment is becoming specific and hard to redirect.

The model generates multiple operational interpretations from that abstraction.
Each interpretation is a hypothesis, not evidence and not a Flow-chan rule.

## Model-generated interpretation bundle

- capacity_aligned
  - Keep new crop-specific seed commitment within the near-term planting surface.
- alternative_affordability
  - After a seed purchase, preserve enough liquid cash above reserve to keep other currently viable crop directions affordable.
- staged_commitment
  - Commit one seed unit per crop per turn rather than taking the full native batch at once.

These are deliberately different readings of the same abstraction.

## Guidance after generation

Do not choose from wording alone.

1. Instantiate each interpretation minimally.
2. Hold seed / seat / opponent / runtime constant.
3. Let each interpretation produce its own Action naturally.
4. Finish the Battle.
5. Compare terminal self and margin against the same control.
6. Keep interpretation candidates unresolved until Battle evidence separates them.
7. A losing interpretation can be closed without rejecting the parent abstraction.
8. If several interpretations survive, generate the next comparison from their observed differences rather than adding a new abstraction immediately.

The loop is:

Abstraction
→ Interpretation Bundle
→ Minimal Operationalization
→ Same-frame Battle
→ Evidence Bundle
→ Re-entry

Flow-chan guides the search; Battle supplies the selection pressure.
